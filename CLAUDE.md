# buggybuilds.org — Nick's project hub

Nick's home page for his side projects. Nick asks for changes by chatting with Claude; Claude edits, checks and pushes to `main`. Cloudflare Workers Builds deploys `public/` about a minute after each push (Worker `buggybuilds-hub`; it reports a "Workers Builds" check run on each commit, so `gh api repos/BuggySmalls/buggybuilds-hub/commits/<sha>/check-runs` shows whether a deploy went through). Static apart from one piece of server code: `src/worker.js`, the Breaker voice relay (Durable Object `Channel`, binding `CHANNEL`, route `/breaker/ws/*` via `run_worker_first`). Every other path is served straight from `public/`. No accounts.

- Off the Hook (Nov 2 2026): `public/hook/index.html`, a single file. Forecasts client call volume at a brokerage taking part in the Anthropic (ANT) IPO: accounts × eligible × request rate → requesters; callers + curious non-requesters + short-fill calls (supply = deal × retail slice × firm cut vs requests × avg request) spread over a trading-day calendar (buzz, IOI window, deadline, pricing night, debut, fade; weekends/holidays skipped). Erlang C reps at peak hour (80/30) and scheduled reps with shrinkage. Quiet/Base/Frenzy presets; settings saved on the device in localStorage `buggybuilds.hook.v1`. Defaults are generic placeholders, not any real firm's data. "What's known" facts are as of Nov 2 2026; update when the price range, date or broker list comes out.
- Breaker (Nov 3 2026, v1.09): `public/breaker/index.html` + `src/worker.js`. Live group voice for snowboarding (Nick wants to talk freely on the way down, so **open mic is the default**) and golf (push to talk option). Join with a name + channel code; invite link `/breaker/?c=CODE`. Mic → 150 Hz high-pass (wind) → AudioWorklet: 16 kHz, voice gate (Wind: Calm/Breezy/Windy sets the threshold, ~720 ms hangover), G.711 µ-law, 40 ms frames (~16 KB/s up while talking). The Worker gives each socket a slot byte and relays every frame to everyone else in the channel (max 12); each listener keeps a jitter buffer per sender and Web Audio mixes them. Nothing is stored. Keepalive ping/pong (auto-response, no wake), auto-reconnect, same phone replaces its old socket (`cid` in localStorage `buggybuilds.breaker.v1`). Screen wake lock + black Pocket mode because phones pause pages when locked. Wrangler can't run in the cloud sandbox (npm blocked); test with a local Durable Object stand-in + Playwright fake mics.
